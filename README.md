# This is edited project for I2C LCD and A button problem
1. Use D1 & D2 for I2C lcd (right 3v3 & right GND)
2. Use D3 D5 D6 for buttons
3. D5 = UP | D6 = DOWN | D7 = OK (A)   

## Notes
Deleted all of non used Configs in A_config.h 

## Display Guide
### ESP8266 — I2C
1. 3V3 — VCC
2. D1 — SLA
3. D2 — SCL
4. GND — GND
